# File Organizer

## Overview
File Organizer is a Java Swing-based desktop application that automatically organizes files into categories based on their extensions.

## Features
- File Categorization
- Preview Before Organizing
- Undo Last Organization
- Custom Categories
- Duplicate File Handling
- Logging System
- File Statistics
- Dark Mode GUI

## Technologies Used
- Java
- Java Swing
- File Handling API
- Collections Framework
- OOP Concepts

## Project Structure
- Main.java
- FileOrganizer.java
- FileOrganizerGUI.java
- LoggerUtil.java
